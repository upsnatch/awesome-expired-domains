# Contribution guidelines

The list is a curation of the best sources, not a catalog of everything about expired domains.

## Adding an item

1. Search the existing entries before adding a new one.
2. Add the item to the matching section, in alphabetical order. Registrar Auctions are the exception: keep the existing order (by prominence in the community).
3. Use this format: `- [Name](https://example.com) - Short description.`
4. Start the description with a capital letter and end it with a period.
5. Describe the project itself. Do not write a slogan.
6. Prefer maintained projects with working documentation.
7. One pull request per item, or a small group of related items.

## Quality bar

Include an entry only if it is genuinely useful for finding, catching, buying, or evaluating expired domains. Skip archived projects, dead sites, and thin affiliate pages.
